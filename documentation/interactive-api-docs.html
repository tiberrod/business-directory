GET

Get All Businesses

🟢 CLIENT ACCESS
GET /api/v1/business

🔐 Access Level

Client Access: This endpoint is open for all users. No authentication required at API level (handled by frontend).

📋 Description

Retrieve a paginated list of all business listings with optional filtering capabilities.

🔧 Query Parameters

Parameter Type Required Description
page integer No Page number for pagination (default: 1)
category string No Filter by business category
featured boolean No Filter featured businesses (1 or 0)
status string No Filter by status: "active" or "inactive" (default: active)
