🚀 API Quick Reference

Business Directory API - Frontend Integration Guide

Base URL: api.php (Local) | index.php (cPanel)
Use these entry points for all API calls - PATH depends on deployment
GET Get All Businesses
Local: api.php/business
cPanel: index.php?endpoint=business
Returns paginated list of businesses.
Params: page, category, featured, status
// Local development fetch('api.php/business?page=1&featured=1') // cPanel production fetch('index.php?endpoint=business&page=1&featured=1')
GET Get Single Business
Local: api.php/business/{id}
cPanel: index.php?endpoint=business&id={id}
Get details of a specific business by ID
// Local development fetch('api.php/business/123') // cPanel production fetch('index.php?endpoint=business&id=123')
GET Search Businesses
Local: api.php/business/search?name={query}
cPanel: index.php?endpoint=search&name={query}
Search businesses by name (partial matching)
// Local development fetch('api.php/business/search?name=coffee') // cPanel production fetch('index.php?endpoint=search&name=coffee')
POST Create Business
Local: api.php/business
cPanel: index.php?endpoint=business (POST method)
Create new business. Use FormData for file uploads.
Fields: business_name, business_contact, business_email, business_address, business_img, business_category, featured
// Local development const formData = new FormData(); formData.append('business_name', 'Coffee Shop'); formData.append('business_contact', '123-456-7890'); fetch('api.php/business', { method: 'POST', body: formData }); // cPanel production const formData = new FormData(); formData.append('business_name', 'Coffee Shop'); formData.append('business_contact', '123-456-7890'); fetch('index.php?endpoint=business', { method: 'POST', body: formData });
PUT Update Business
Local: api.php/business/{id}
cPanel: index.php?endpoint=business&id={id} (PUT method)
Update existing business. Only ID is required, other fields optional.
// Local development fetch('api.php/business/123', { method: 'PUT', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ business_name: 'New Name' }) }); // cPanel production fetch('index.php?endpoint=business&id=123', { method: 'PUT', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ business_name: 'New Name' }) });
DELETE Delete Business
Local: api.php/business/{id}
cPanel: index.php?endpoint=business&id={id} (DELETE method)
Soft delete a business (sets status to inactive)
// Local development fetch('api.php/business/123', { method: 'DELETE' }); // cPanel production fetch('index.php?endpoint=business&id=123', { method: 'DELETE' });

📊 Response Status Codes

All responses include a status field and appropriate HTTP status codes:

200 Success - Operation completed successfully
400 Bad Request - Invalid parameters or missing required fields
404 Not Found - Resource doesn't exist
500 Server Error - Internal server error

Response Format:

// Success Response (GET /business) { "status": 200, "message": "Success", "total": 25, "page": 1, "per_page": 10, "filters_applied": {...}, "data": [...] } // Success Response (GET /business/{id}) { "status": 200, "message": "Success", "data": { "id": 1, "business_name": "Sample Restaurant", "business_contact": "123-456-7890", "business_email": "info@sample.com", "business_address": "123 Main St", "business_category": "restaurant", "business_img_url": "https://example.com/images/sample.jpg", "status": 1, "is_featured": 1 } } // Error Response { "status": "error", "message": "Error description", "error": "Detailed error information" }

� Deployment Environment Detection

// Auto-detect environment and use appropriate endpoint function getApiUrl(endpoint) { const isLocal = window.location.hostname === 'localhost' || window.location.hostname === '127.0.0.1'; if (isLocal) { // Local development - uses PATH_INFO return `api.php/${endpoint}`; } else { // cPanel production - uses query parameters return `index.php?endpoint=${endpoint}`; } } // Usage examples: fetch(getApiUrl('business')) // Auto-selects correct URL fetch(getApiUrl('business') + '&id=123') // For specific business fetch(getApiUrl('search') + '&name=coffee') // For search

�💡 Integration Tips

  • Environment Detection: Use the helper function above for automatic URL selection
  • Local Development: Use api.php with PATH_INFO routing
  • cPanel Production: Use index.php with query parameters
  • File Uploads: Use FormData with multipart/form-data
  • JSON Data: Use application/json content type
  • Error Handling: Always check the status field in responses
  • CORS: API supports cross-origin requests from any domain
  • Image URLs: Business images include full URLs in responses
  • Response Status: Success responses have status: 200, errors have status: "error"
